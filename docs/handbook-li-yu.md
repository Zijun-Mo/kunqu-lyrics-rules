# 昆曲填词规则手册｜李渔《李笠翁曲话》

李渔所谓“填词”包括传奇创作、依谱写唱词和舞台运用。若只填一支昆曲，先用本手册第二、三节，再试唱。写一出或一部传奇时，再用结构、宾白和演习各节。

**底本范围。** 以国家图书馆藏大中书局 1933 年独立刊本界定全书，收《词曲部》六章、《演习部》五章，共 53 款，另有〈填词余论〉及〈变调〉两篇改本。逐页阅读以《闲情偶寄》对应的 11 个可检索正文网页为单位，以识典古籍文字补足缺漏。网页行号是此次文本检索器的定位，另标原文章款，便于在原站复核。印本著录确认版次与目录，逐页范围对应下列 11 个电子正文页。 [1933 年单行本著录与目录](https://commons.wikimedia.org/wiki/File:NLC416-12jh000490-82770_李笠翁曲話.pdf) · [中国社科院出版说明](https://www.cass.cn/keyandongtai/baokanchuban/201903/t20190301_4841051.shtml)

**怎样用规则。** 正字位、句格、韵位和字声，以具体曲牌、体式和所选谱本的明文为准。李渔的选韵、发调、审词和排演意见列为人工检查或可选提示。涉及李渔与王骥德不同口径处，记录作者、韵书和曲谱依据后再判词格。

## 一、结构｜写传奇前先定主线

| 编号 | 原文章款 | 写作检查 |
|---|---|---|
| S01 | 戒讽刺 | 写完剧情梗概后检查是否借剧影射泄愤。匿名和虚构的人物若可被轻易对号入座，也审其情节作用。 |
| S02 | 立主脑 | 用一句话写出中心人物与主事件。逐出标记它如何引发、推进或收束主事件。 |
| S03 | 脱窠臼 | 与同题旧戏比核情节与人物动机。旧事可写出新意，检出仅拼接旧桥段的地方。 |
| S04 | 密针线 | 对读前后场，逐一追查伏笔、道具、已知信息和人物行动的来龙去脉。重要暗示应有下落。 |
| S05 | 减头绪 | 合并功能相同的人物和支线。确认次要人物能推动情节或改变关系，主线容易跟住。 |
| S06 | 戒荒唐 | 核人物行事、物件与场面是否符合设定。奇事也应让观众看懂缘由与结果。 |
| S07 | 审虚实 | 标明寓言、虚构与可考史事。采用真实姓名与事迹时查考关键事实，审虚构部分能否与之相容。 |

## 二、词采｜逐句先读，再让人听

| 编号 | 原文章款 | 写作检查 |
|---|---|---|
| C01 | 贵显浅 | 让听者离开词本听一遍。只凭唱白便能明白所指和情意，用口头易懂的字句承载较深意思。 |
| C02 | 重机趣 | 审场面推进有没有关节，语言与动作有没有趣味。连严肃情节也要写出人物行动，少用僵硬说理。 |
| C03 | 戒浮泛 | 遣词随角色、身份、心境而异。景物要能引出此人此刻的情，圈出移给别角、别场仍然一样的泛泛景语。 |
| C04 | 忌填塞 | 删去用来炫学的僻典、人名堆列和套用熟句。保留的典故和口头成语应自然、好懂、有效。 |

## 三、音律｜先定谱和韵，再填唱词

| 编号 | 原文章款 | 写作检查 |
|---|---|---|
| Y01 | 恪守词韵 | 先定所用韵书，查谱标出的应押、暗押及不宜押处。李渔以一出贯一韵为通则，鱼模例外见 Y03。材料不全时，先核具体曲体与韵段。 |
| Y02 | 凛遵曲谱 | 在定谱的句数、字数、声类和韵格内改词。引用集曲、犯调或摊破先查接腔。自创新组合须反复唱验音调衔接，也要核曲名和文义能否贯通。 |
| Y03 | 鱼模当分 | 李渔认为《中原音韵》是北韵，借作南曲参考时须辨入声，并宜把鱼、模分开。理想是全出不混，两者为不同曲采用时，至少每支曲内守住其中一类。这个分法随李渔采用的南韵口径记录。 |
| Y04 | 廉监宜避 | 悠扬长套宜避监咸、廉纤，因可用熟字少且唱口有碍。急板小曲或角色声口相合可以用，侵寻另论。先查韵脚够不够自然地写完。 |
| Y05 | 拗句难好 | 碰到谱定声序与常用语序相拗的句节，先找贴合语义的熟语，可少量调整顺序后试唱。用原谱核对例句，别从一个例词推定全牌格律。 |
| Y06 | 合韵易重 | 写前腔或幺篇的合前格式时，把复用的后段纳入当前每支的查重范围，核新写前段与后段是否重押同一字。合唱内容还须是每位唱者当场都能说的。 |
| Y07 | 慎用上声 | 试唱上声密集或激昂处的关键词。李渔避一句连续二、三、四个上声，提醒上声入曲偏低、入白偏高，激昂紧处另审阴阳与发调效果。先服从谱位，再判断该用字是否拖低语势。 |
| Y08 | 少填入韵 | 李渔主张南曲遇入声字保留入声唱法，并建议初学南曲少选入声韵脚。北曲可用本为入声的字作韵脚，按北曲派声归部。老手及有据曲例可通融，曲中入声、入声韵脚、借入代平是三种情形。 |
| Y09 | 别解务头 | 全曲找最能发调动情的一句，每句再找一两个提劲的字。通篇照谱并审字声、文义。按谱例另标具体揭腔、转腔处的务头，李渔还把它用来评价曲句重心。 |

## 四、宾白、科诨与格局｜写给台上说、给台下听

| 编号 | 原文章款 | 写作检查 |
|---|---|---|
| B01 | 宾白总论 | 将对白与唱词连起来读。白应能引出或补足曲，曲后的白应接得住人物情节。 |
| B02 | 声务铿锵 | 出声检查白的句末和平仄起伏。平仄交替是行文办法。难调处可试上声过渡，以听来自然为准。 |
| B03 | 语求肖似 | 让各角色用各自身份、心思和惯用语说话。包括反面角色，也要写出其自己的动机和声口。 |
| B04 | 词别繁减 | 新情节靠宾白交代足够的来龙去脉。先写足可理解的版本，再出声删去可减之句，勿把要点留待演员临场补说。 |
| B05 | 字分南北 | 分辨配南曲和配北曲的宾白口吻。依场景、角色和套式择词，遇南北相间查具体演法。 |
| B06 | 文贵洁净 | 白写到信息足、字句紧。隔一段时间再读，删可从前后文推得的重复交代。 |
| B07 | 意取尖新 | 在关键白句求言语鲜活、有独到意思，改掉人云亦云的套话。 |
| B08 | 少用方言 | 让外地听者试听，确认方言词能随情境听懂。只在有角色和现场需要时保留。 |
| B09 | 时防漏孔 | 全剧交叉核同一人物的身份、称谓、仪制和应答。检查叫场、承诺或前白提出的问题是否有回应。 |
| Q01 | 戒淫亵 | 审笑料的分寸，必要时用暗示或转喻。 |
| Q02 | 忌俗恶 | 用易懂的笑料，删去陈腐、粗鄙或只有术语才懂的包袱。 |
| Q03 | 重关系 | 检查笑料与人物、关目或严肃情意的联系。主要脚色也可诙谐，分量随场面而定。 |
| Q04 | 贵自然 | 说明笑点由哪句白、哪个动作或哪个处境引发，削去强塞进去的笑话。 |
| G01 | 家门 | 待全剧结构明了再写家门，先把全剧要旨说准。开场曲可含蓄引意，家门说清题旨，收语宜概全篇。 |
| G02 | 冲场 | 用于李渔讨论的传奇开局。次出主要脚色登场前后，用引子和定场白让观众听见身份、心事和全剧伏线。采用不同演出本时查场次。 |
| G03 | 出脚色 | 主要脚色宜早出场。李渔建议前四五出内见主要人物，审观众是否误认曲中主角。 |
| G04 | 小收煞 | 上半本收处留下足以牵引下半本的悬念，审观众能看见问题但猜不尽结果。 |
| G05 | 大收煞 | 全本末收拢主要人物和线索，检查会合原因、情绪落点与余味。此处说全剧关目，曲套尾牌另依谱。 |
| G06 | 填词余论 | 校改时兼看文本与舞台。对精巧照应可记录其效果，对作者原意的推断须有凭据。 |

## 五、演习｜用排练发现词稿的问题

| 编号 | 原文章款 | 写作或排演检查 |
|---|---|---|
| E01 | 选剧总论、别古今 | 先以有据旧戏熟悉腔板，再让懂文义和曲律的人试新作。选剧同时看情理、词曲和演出条件。 |
| E02 | 剂冷热 | 冷场审是否情意真实、足以动人。热闹场也审内容和分量；可在排演中搭配。 |
| E03 | 缩长为短 | 若预备缩演，标可裁场次与衔接白。被省掉的动作如果影响后场理解，要在前后白中交代，保留完整收束。 |
| E04 | 变旧成新 | 改编先划出有谱依据的唱词和主要关目，再改小白、笑料、舞台行动或补剧情漏洞，逐项试排接缝。 |
| E05 | 附《琵琶记·寻夫》改本 | 查独行、护送和后续照拂有没有交代。改例以既有人物小二解决随行问题，并补辞别与托付。 |
| E06 | 附《明珠记·煎茶》改本 | 用角色关系核对递茶、传信等动作的可信度。改例用采苹承接这些行动，曲文、音调沿旧，主要改白与场面安排。 |
| P01 | 解明曲意 | 试唱前要求每位唱者说清唱给谁听、问答讲什么、情绪怎样转，声音、神态和动作应能表明。 |
| P02 | 调熟字音 | 辨平仄阴阳及字的出、收，慢腔留出字头、正音、字尾和余音所需时间，快板以正音为主。附带音避免让听者误以为另有字。 |
| P03 | 字忌模糊 | 从试唱第一遍验字音。让听者听写疑难字，修正掉字、糊字和因拖腔而难辨的地方。 |
| P04 | 曲严分合 | 逐句问是谁的口吻与意思。各角各抒己意用分唱，同一行动或共同意态才用合唱，并核原谱和实际分工。 |
| P05 | 锣鼓忌杂 | 连排白末、锣鼓和曲起。须让关键信息说完，锣鼓停稳再接该说的话，唱词起句也要听清。 |
| P06 | 吹合宜低 | 先核人声能否领腔与被听清。李渔建议声强的领唱可试用较低器乐相傍，依演员和乐队条件使用。局部先清唱后合奏。 |
| P07 | 高低抑扬 | 教白先标句群、分句、字词的主次，再定哪些重读、高读、放慢，哪些低读轻带。长白与定场白均需变化。 |
| P08 | 缓急顿挫 | 同一意脉连贯说，话题转折处留顿。把停顿标入排演本，再依听感调整标点与白口的差异。 |
| P09 | 衣冠恶习 | 看服饰是否交代角色年龄、身份与动作需要。舞衣应容许转身和舒展。李渔所举青蓝衣、巾帽和纹样按历史演出语境参考。 |
| P10 | 声音恶习 | 审方音、怪声在角色、地点和笑料上有无根据，听当地及外地观众是否理解。 |
| P11 | 语言恶习 | “呀”留给意外，“且住”用于转念或犹疑。下场诗后通常就收，只在剧情尚需余下角色说完要紧话时保留。 |
| P12 | 科诨恶习 | 试演后找观众已经能预料的程式化笑料，以及与本戏无关的串戏。查它们是否打断关目或削弱情意。 |
