# 昆曲填词规则手册
## 依据王骥德《曲律》

本手册采用明代王骥德《曲律》四卷的可选取文字版。全书是古典曲论，涵盖南北曲填词、唱腔、联套和剧戏。下文顺原书篇次提取规则，末附按字位校词表与阅读清单。王氏的规则用于他讨论的曲体与声韵体系。具体填写哪一支昆曲，仍需取该牌、该体、该唱本的谱。

**原书文字入口**　[卷一](https://www.shidianguji.com/zh/book/CADAL02111067/chapter/1lctucgj58oqa) · [卷二](https://www.shidianguji.com/zh/book/CADAL02111067/chapter/1lctucixrv9da) · [卷三](https://www.shidianguji.com/book/CADAL02111067/chapter/1lctuckowm4gq) · [卷四](https://www.shidianguji.com/zh/book/CADAL02111067/chapter/1lctucn2fnnzm) · [后跋](https://www.shidianguji.com/zh/book/CADAL02111067/chapter/1lctucobus7pl)。卷三尾声、宾白、插科等处的转录有脱误，同书的[维基文库文字版](https://zh.wikisource.org/zh-hans/曲律)用于补读这些篇章，以及核对声序和〈论曲禁〉的分条。

## 卷一　先辨曲体和所用曲牌

| 篇 | 写作时怎样用 |
|---|---|
| 第一〈论曲源〉 | 王氏追述歌词从乐府、诗、词到南北曲的流变，供识曲体史 |
| 第二〈总论南北曲〉 | 南北曲的板、弦、字密与声情各有传统，声韵不可直接互套。北曲字较密、南曲较舒缓是概括，具体作品依谱 |
| 第三〈论调名〉 | 先定南北、宫调、牌名、本序或变体，再读字格。同名词牌、南北同名牌，调与声可能全异。本序看前引，换头看实际换了哪几句。尾声的句格随所承宫调。商黄合犯依其原列先商后黄。牌名、别名与宫调目录用来确认底本身份 |

**开工先写下**　南或北、宫调、牌名、体式、所依曲俗或唱本、谱页、单支或联套。

## 卷二　字声、韵部、板眼及文辞

### 第四至第十一　先核能否按谱成声

| 篇 | 必须核对的项目 | 王氏允许或建议的处理 |
|---|---|---|
| 第四〈论宫调〉 | 曲牌归宫、套中衔接和弦板相协。原书的历史宫调与乐律表是用来辨名、辨体的材料 | 宫调的声情概括可协助选牌。接曲时要看具体声腔和板 |
| 第五〈论平仄〉 | 谱定平、仄、上、去，照所定字位填。某处明确用连续上去或去上，两字声类和先后顺序一并核对 | 王氏说有的牌位两种声序皆可。南曲在用字困难时可酌验入代平、上、去。句中能代与韵脚能代分别查，韵脚少用入代。两上、两去相连及单句四同声是他重视的唱口问题，原文也举成词、截板等通融 |
| 第六〈论阴阳〉 | 已定阴阳的腔位，逐字核阴阳与旋律抑扬。不能以“都是平声”代替该项检查。王氏亦论上、去、入的清浊差异 | 他以阴搭上、阳搭去为常见经验，同时举有些揭腔用阳字效果更好。南北术语和提抑习惯分读，具体字位依曲例 |
| 第七〈论韵〉 | 确认谱定韵位、韵部、韵脚声类。北剧按一折一韵处理，留意有意不押的句位。南曲逐支依韵辨读，不能把相近的韵部随意混押 | 王氏讨论时以《中原音韵》为北曲的重要依据，也明辨其用于南曲时的局限。个别字在韵脚的协韵读法，不能自动搬到句中 |
| 第八〈论闭口字〉 | 原韵体系区分开口与闭口时，押韵保留这条界限。侵寻、监咸、廉纤等不能因为现代听感相近，便并入其余韵部 | 五音、收音和吟唱难处另外处理。原文特论若干历史入声的散协，应用到具体韵字时须回原韵体系核对 |
| 第九〈论务头〉 | 先在指定曲牌查关键揭腔、转腔的字与句。优秀谱例可反复唱，以确定位置 | 在该处选能唱响、意义精确的字。各牌务头可能在一字、数字或数句 |
| 第十〈论腔调〉 | 音与字相合，转腔、过字和出收不能使听者误辨。字多腔少时要会赶、歇 | 原文分北弦、南板，也提其时代的吴音标准与昆山腔历史。读唱全句，核验圆转、流畅和响度 |
| 第十一〈论板眼〉 | 分清落在字头、字中或字末的板，合唱衔接时核前后板位。抢前、拖后都要检出 | 旧曲点板有谱例可循，清唱随腔的余地和有鼓板合奏的情形分开判断 |

**入声判定。** 北曲在所定韵书中查原入声字派作哪一声，同时记录韵部。南曲先标原入声，再记录该字位为何可代、怎样唱。王氏的通融有语境，不能据此把任一入声字直接填入任一声位。同一韵脚若谱规定上声，即使候选字部内相同，它仍须通过上声一项。（第五至第八）

**两种容易误判的情形。** ① 谱明定「去上」时，换成「上去」便违该格。同牌一条例词恰好是「去上」时，先记录例声，查证是否必用。② 谱定阴平时，阳平字虽和它同属平声，仍要另择。纸面格律成立后再试唱，以确认咬字、收韵、落板和过搭。

### 第十二至第二十　逐字逐句校词

| 篇 | 可执行的规则 |
|---|---|
| 第十二〈论须识字〉 | 先判句中义，再查读音、反切和所归韵。多音字尤其要核。原书用倩、车等字例说明，形同也可能异义、异声、异韵 |
| 第十三〈论须读书〉 | 广读作品和典籍，把材料消化成自然用语。留得下的典故须使听者明白 |
| 第十四〈论家数〉 | 本色重人物情态，文词重文采，各可失之俗或晦。选定作品所需的文辞层次，唱词要仍然像角色的话 |
| 第十五〈论声调〉 | 朗读、吟咏再唱，检查词的轻重、清浊、响亮和转折，修掉生硬和拗口处 |
| 第十六〈论章法〉 | 起承转收先有安排。好句要服务整支、整套的脉络 |
| 第十七〈论句法〉 | 句读与固定句格按谱。句间语意相承，出语清楚自然，辞意和声调一起炼 |
| 第十八〈论字法〉 | 韵脚要贴切，务头宜用响字。复查全篇重复字和费唱的闭口字。题目也要让人容易领会 |
| 第十九〈论衬字〉 | 先抄正字，衬字单列。快板、南曲尤其核时值，避免衬字抢去正字的实板或使正腔难辨。对口曲可因说话需要加衬，长套及大曲宁少加。不能从唱词表面长度反推正字数 |
| 第二十〈论对偶〉 | 谱格要求对偶的地方配对。核句法、语义、轻重、隔句、隔调或复叠形式。自然成立的借对可用 |

## 卷三　过搭、曲禁、套式与剧场

### 第二十一至第二十九　定套与修订

| 篇 | 可执行的规则 |
|---|---|
| 第二十一〈论用事〉 | 典故须准确、贴境、唱出来能懂。能化入人物自己的话最好。借古句宜少，作对时另找相称的回应 |
| 第二十二〈论过搭〉 | 核前曲曲尾与后曲曲首，具体比较腔的粗细、板的紧慢和相接的节拍。按书列宫调界限与有例可循的出入。集曲的接句须唱得顺。用赚、过门或宾白时，看是否能承担过渡 |
| 第二十三〈论曲禁〉 | 用下表逐项核查。王氏书末容许不能尽免时优先改去最显眼的毛病。明确谱律、可通融条目、传播时的辞意忌病各依其条件 |
| 第二十四〈论套数〉 | 先定一个主意和整体结构，再排牌、写曲。成套依次序，上一调尾与下一调首可互相引带。避免逐牌各起一意 |
| 第二十五〈论小令〉 | 篇短字少，要含而有味。删掉凑字，每句要有效 |
| 第二十六〈论咏物〉 | 使听者能认出所咏之物，着重它的情状或作用。避免平铺外形 |
| 第二十七〈论俳谐〉 | 幽默靠合场的机趣。口语须自然，粗话和刻意布置都会损伤笑意 |
| 第二十八〈论险韵〉 | 可用难韵，但必须语意稳、遣词俊。因难押而损害语意时换字或换韵部 |
| 第二十九〈论巧体〉 | 短柱、数字、集句等均有实例。特殊做法要确有成效，先辨体式再用 |

**〈论曲禁〉查病表。** 保留作者讨论的类别和例外。原书结语称四十条，两处电子文字的分项及连写有差异，以下按可辨内容归并，项目原注可回查第二十三。

| 层面 | 检查内容 |
|---|---|
| 韵与同音 | 重韵、借韵、犯韵、犯声、平头、合脚、闭口韵混押。分清重韵是重押某字，借韵是混押邻部。同音相犯还要看它发生在韵脚还是句内。长套与戏曲重韵原注从宽 |
| 四声及清浊 | 上上、去去叠用，指定上去或去上倒用，连续三入或四同声，阴阳错用，闭口字连用，韵脚多以入代平，双声与叠韵累用。重叠成词、恰合板式或有明许的情形按前文或条下注解判断 |
| 字句与叙意 | 陈腐、生造、俚俗、蹇涩、粗鄙、错乱、蹈袭、沾唇、拗嗓、艰懂的方言、语病、将无关字句拉入题内，过文过晦、经史学究时文气，重字与衬字过多，堆积学问、错用典故 |
| 音乐和结构 | 宫调乱用、紧慢失次、对偶不整。以本体和套例验证 |

### 第三十至第三十八　从单支到一出戏

| 篇 | 可执行的规则 |
|---|---|
| 第三十〈论剧戏〉 | 设计全本和每折的结构。重要情节可铺陈，次要场面宜收。分清北剧一人主唱与南戏分唱的历史体例。角色和场景都要有作用 |
| 第三十一〈论引子〉 | 以人物声口说出登场时最紧要的事。按引子谱认底板与不押韵句的点断 |
| 第三十二〈论过曲〉 | 大曲可用文采而要听懂，小曲贴近日常声口。韵脚要稳，勿因趁韵损伤原意。王氏乐用一韵到底，剧曲重韵好过刻意避重到牵强 |
| 第三十三〈论尾声〉 | 尾声负责收束全套。末句仍须用心。按宫调和套式分平煞、仄煞等，各有固定体。原书另列有不必加尾声的重复支数和套例 |
| 第三十四〈论宾白〉 | 定场白可以整饬，对口白宜明白简洁。调节长短、平仄与情意。根据角色和事由定口吻和长度 |
| 第三十五〈论插科〉 | 曲情偏冷时可借合适的净丑科诨提起场面。笑话要贴情势，牵强就删 |
| 第三十六〈论落诗〉 | 要让演员好记、听者好懂。借古句须贴切，避免为显新奇拼合晦涩句子 |
| 第三十七〈论部色〉 | 先识所写脚色的传统分工。原书在这里辨 历史称谓和班社名色 |
| 第三十八〈论讹字〉 | 对可疑唱字，同时用音义、曲韵、对偶、剧情和旧本交叉校对。流传很广的唱法也可能源于讹字 |

## 卷三、卷四　杂论与附记

- **第三十九〈杂论〉上。** 南北曲辞语和用韵各有体。怎样处置衬字、曲白、典故与历史本事，要看整段的情理和可演性。对照旧剧宜用整体声音和情境判断。王氏也明说，机械避声致语意不通时应回头择字、比较唱法。
- **第三十九〈杂论〉下。** 将旧谱、当时唱法、作者辞意并置。碰到异文，先问版本是否改变了字格或唱法。作者评沈璟、汤显祖及诸家时，着重不同作品的守格、文辞和可唱性。其对具体剧目、作者、韵部风格的判断作为示例。林钟商等谱式有个别专用谱号以小图承载，保留原处位置。
- **第四十〈论曲亨屯〉。** 记演唱兴衰所受的场地、演员、曲本、观众、节拍和乐器等条件。可作为演出检视。附后的毛以燧跋和诗记录交游和付刻，不增设曲律。

## 填词与验收表

1. **查牌。** 抄宫调、曲牌体式、版次、套序和用韵体系。先抄 1 份例词及正衬板位，另外列明谱中允许变化的地方。
2. **定韵。** 标出必押、谱明示不押及待核。每个韵脚先核归部，再核本位的四声、阴阳。记录同字异音、南北入声及有据通押。
3. **填正衬。** 正字先填，标出谱定声序、务头、板位、对偶或句读。衬字另列并试拍。古人例词出现过的声类先记为例见。
4. **试唱。** 依谱拍唱，听字头、收韵和同套接处。旧谱换词时逐位听字声和腔匹配，发现拗嗓或走字先复查读音与板位。
5. **注明结论。** 明载的规则有违，判失律。书或谱支持的变通写出出处。谱注难辨、只有例词、尚未试唱时，分别记下待核项。
