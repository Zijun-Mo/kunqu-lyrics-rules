# 昆曲填词检查规则表

本表用于辅助昆曲填词的 Agent。检查范围为依谱填词、用字声韵、押韵、句格，以及与词稿直接相关的文义。单支依曲牌谱，填一套时才查套序、韵段与尾牌。唱腔、板眼、发声、宾白、角色分唱与排演属于另行研究的内容。

**一次核查的输入。** I01 为必需，提交目标曲牌和任务内容。核查现稿时附词稿，起草时给拟写主题或文字素材。若同名异调、别体或底本选择会改变判定，Agent 先据来源缩小范围，只询问影响结果的差别。I02 为可选，只有文义判断依赖人物、典故或场景时才补。

**判定。** 字格和韵格以所选底谱及适用曲韵为准。区分「明确规定／允许通融／仅例见／未知」。证据足以证明违反强制约束才报「失律」。有多种读法时，用每个完整候选同时核声类、阴阳与归部。无任何候选能同时满足已确认约束时才报失律。证据不足或读法有合格也有不合格时，报「待核」。已证不适用时跳过。诊断给出句位、问题与出处。「提示」用于供 AI 和用户审词。

**工作方式。** Agent 从底谱与韵书提取对齐和默认口径，检查结果直接交给后续审词环节。底谱准备、对齐与异文核实是共同前置步骤。

曲论和历次整理见 [《曲律》版手册](handbook-qulu.md)、[《李笠翁曲话》版手册](handbook-li-yu.md)、[历史对照](handbook-comparison.md)。

## 二、AI 审词

按适用项审读。每条意见指明具体字句、理由和可考虑的改法。有备选词时，改后回程序复核句格与声韵。文本缺少语境时，意见只涵盖能从词稿确认的部分。
