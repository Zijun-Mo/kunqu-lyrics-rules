# 昆曲填词检查规则表

依据[《昆曲填词规则手册》王骥德《曲律》版](handbook-qulu.md)提取。表中「强制」指已为本曲、本体和所选谱本确认的要求。「提示」用于定位疑似曲病，供人工复核。 李渔口径的补充见[李渔《李笠翁曲话》版手册](handbook-li-yu.md)与[两书双向对照](handbook-comparison.md)。

**输入。** 曲谱模板标明南北、宫调、曲牌、体式、版本，以及曲句、正字位、句读、韵位、声类、允许的通融和板位。填词稿以唱字对齐字位，另标衬字、叠唱和宾白。音韵字典按所用曲韵体系记录每字的候选读法、四声、阴阳、韵部和历史入声派法。联套与板眼检查另需结构化套谱或唱谱。每条谱约束保留出处以及「明确规定／允许通融／仅例见／未知」标记。 启用李渔南曲韵法时，另录支曲边界及有出处的鱼、模细类。核「合前」须标复用段落及其对应韵位。核南曲入韵时，历史入声身份、实际采用声类和借代情况分别记录。

**判定。** 适用条件明确为假时返回「不适用」。条件或输入不明，且无法确定结果时返回「待核」。读法未定时保留完整候选元组，用同一读法同时验声类、阴阳、韵部和入声派法。全部候选均违强制约束，且候选与约束均完备时，判「失律」；候选既有合格又有不合格，返回「待核」。只有每项规则取得必要证据并通过，才能报告相应检查通过。若各条分别可过，但不存在能同时满足全部硬约束的同一候选，仍然失律。已明确量化的例外在判定前应用。诊断至少定位到适用的曲牌、曲句或字位，并给出期望值、实际值和依据。

例如，同一韵脚若要求「本韵部＋上声」，一个候选读法是「本韵部＋去声」，另一个是「他韵部＋上声」，两种读法都不能通过。若词稿含多音字且有一个完整候选能通过，另一个不能通过，则在选定唱读前标「待核」。逐字检查之外，词意、是否本色、典故贴切和实际吐字仍由人工或试唱核对。

## 二、人工检查
