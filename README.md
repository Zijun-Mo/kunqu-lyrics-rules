# 昆曲填词规则

本仓库整理昆曲填词的程序检查与人工审曲规则，记录每项检查的数据需求、原始出处与适用条件。

实际核查时，先确定南北曲、宫调、曲牌、体式和底谱。规则表区分有明确谱证的约束、提示与待核事项，并为每项检查列出所需材料。现阶段提供文档与建库清单。
