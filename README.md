# 昆曲填词规则

本仓库为辅助昆曲填词的 Agent 整理依谱填词规则，涵盖句格、声韵、押韵、正衬字与词稿文义。

| 文档 | 内容 |
|---|---|
| [昆曲填词检查规则表](docs/checklist.md) | 28 条程序检查、7 项 AI 审词，列出参考来源与两类任务输入。 |
| [王骥德《曲律》版规则手册](docs/handbook-qulu.md) | 按原书篇次整理填词、用韵、联套与试唱规则。 |
| [李渔《李笠翁曲话》版规则手册](docs/handbook-li-yu.md) | 整理制曲、宾白和演习规则，附逐页阅读与校补记录。 |
| [两书规则双向对照](docs/handbook-comparison.md) | 历史对照，留存两书逐条核对及口径差异。 |
| [原始资料目录](docs/sources.md) | 曲谱、曲韵、戏本、录音研究线索，以及【皂罗袍】、【天净沙】的查用记录。 |

给出目标曲牌和现稿即可开始校词。起草任务给目标曲牌和拟写主题或素材。角色、场景或用典线索按需补充。联套按所选套谱核查。
